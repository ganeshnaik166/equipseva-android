retry…"), Profile shows "Network problem", Sign out is unreachable; only `pm clear` recovered. Host checks ruled out the anon key
and the network. Cause: the app pins **supabase-kt 3.0.3**, which only refreshes on a timer (stopped by Android lifecycle
