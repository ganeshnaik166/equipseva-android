## Visual and workflow contract

Follow the root `docs/UI_THEME_PAGE_PLAN_2026-09-12.md`: lime `#C6FF00` primary actions with near-black text, soft-white/light and corresponding dark surfaces, original logo unchanged. Page titles use Space Grotesk 28/34sp 600; body Inter 16/24sp 400; labels 14–16sp 600; supporting text 12–14sp 400/500. Card/hero/input radii are 24/28/16dp; pill primary buttons have **52dp minimum height**, growing for wrapping text. Do not interpret the 24dp card radius as a 24sp card-title requirement. Preserve labeled engineer tabs **Home / Jobs / Earnings / Profile** (`N:111`); do not add a fifth tab or move a backend gate merely to match an illustration.

One dominant action per state. Put active work and required setup before growth content; status text always accompanies color. Lime means emphasis, never evidence of verification, settlement or clinical/calibration success. Use adaptive scrolling and semantic labels; maps and thumbnails must have usable text alternatives. Keep all current features reachable, with advanced options grouped rather than removed. New links or next-job previews mentioned below require explicit bindings/data support; they do not exist merely because the plan names them.
